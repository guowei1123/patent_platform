# 专利交底书智能体二、三期

## 二期：材料、图片与章节联动

- 上传入口支持 DOCX、可提取文字的 PDF、PNG 和 JPEG；扫描 PDF 未提取到文字时明确要求先做 OCR。
- 图片保留原始格式检查结果；“图文交叉检查”读取已保存的图片、图注和技术方案，返回图中可读标号、核验结论和可定位的问题。服务不可用、原图丢失或图片不可读时一律标记为未完成，不能显示通过。
- 建立章节依赖：技术领域影响背景和技术方案；背景影响方案、效果和保护点；技术方案影响效果和保护点等。修改后只标记受影响章节供人工复核，不自动覆盖无关正文。

## 三期：检索证据隔离

- 只有用户点击“检索相关专利”后，系统才调用已有专利检索服务；关键词和结果随交底书版本保存。
- 检索结果与用户材料、技术事实分开保存。选择文献后可生成背景描述候选和待人工比对的差异说明。
- 分析提示词和界面都限制检索结果：不输出新颖性、创造性或授权结论；不把外部专利技术特征自动写入用户技术方案。
- 背景候选只能由用户点击“载入背景编辑草稿”后进入编辑器，仍需用户保存；差异说明仅作为审阅信息展示。
